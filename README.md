# pickpack

It's an autonomous warehouse execution system: a continuous stream of incoming orders is grouped into spatially-tight batches, each item is allocated from the nearest in-stock location (combining locations when one runs short), and the picks are sequenced into a near-optimal route with A* + TSP. A fleet of robots executes these batches in parallel, each delivering to the least-busy, nearest packing station (scored by distance, queue, and utilization), with the whole operation continuously re-balancing as new orders arrive. Everything is visualized in a real-time 3D digital twin with a per-robot first-person view. The benchmark page proves the payoff by running our method against the standard serpentine (snake) picking heuristic on an identical order stream, showing higher throughput and less travel per order, especially on multi-order batches.
