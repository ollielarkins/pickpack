ALGORITHM LEADERBOARD — PickPack Efficiency Index (PEI) figures are simulated benchmark runs · same order stream / fleet / warehouse [ reset weights ]
RANKING
#ALGORITHM T (o/min)D (m/ord)L (s)C (ms) PEI 
SCORING MODEL
PEI = 100 · [ w₁·T̂ + w₂·D̂ + w₃·L̂ + w₄·Ĉ ]
where   T̂=T/7.0   D̂=1−D/160   L̂=1−L/200   Ĉ=1−C/250
Weights
Metrics
T — Throughput, orders/min  (higher better)
D — Travel per order, metres  (lower better) — the efficiency number
L — Avg order latency, seconds  (lower better)
C — Route-solve compute, ms/batch  (lower better)
